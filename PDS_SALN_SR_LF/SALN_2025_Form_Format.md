## Summary of All Fields

| Section | Field |
|---------|-------|
| **Compliance** | Type of filing (Assumption / Annual / Exit), Date |
| **Declarant** | Family Name, First Name, M.I., Position, Agency/Office, Office Address |
| **Spouse** | Family Name, First Name, M.I., Position, Agency/Office, Office Address |
| **Filing Mode** | Joint / Separate / Not Applicable |
| **Multiple Marriages** | Name(s) of spouse(s) or N/A |
| **Children** | Name of child, Age (for each unmarried child below 18 in household) |
| **Real Properties** | Description, Kind, Exact Location, Assessed Value, Current Fair Market Value, Acquisition Year, Mode, Cost |
| **Personal Properties** | Description, Acquisition Year, Acquisition Cost/Amount |
| **Totals** | Subtotal (Real), Subtotal (Personal), Total Assets, Total Liabilities, Net Worth |
| **Liabilities** | Nature, Name of Creditors, Outstanding Balance |
| **Business Interests** | Name of Entity/Business, Business Address, Nature of Interest/Connection, Date of Acquisition |
| **Relatives in Gov't** | Name of Relative, Relationship, Position, Agency/Office and Address |
| **Certification** | Declarant's oath and authorization |
| **Signatures** | Signature of Declarant (×2), Government Issued ID, ID No., Date Issued |
| **Oath** | Subscribed and sworn, Person Administering Oath |
